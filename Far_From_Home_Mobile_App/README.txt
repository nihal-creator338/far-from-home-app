FAR FROM HOME — MOBILE APP PROTOTYPE

This is an installable Progressive Web App (PWA), not a compiled APK.

TO INSTALL ON ANDROID
1. Host the contents of this folder on an HTTPS website.
2. Open the website in Chrome.
3. Tap Install if shown, or browser menu > Install app / Add to Home Screen.

TO INSTALL ON IPHONE
1. Open the hosted website in Safari.
2. Tap Share > Add to Home Screen.

LOCAL TEST
Run: python -m http.server 8000
Then open http://localhost:8000 (service workers do not work from file://).

Includes the supplied prototype, mobile bottom navigation, PWA manifest, icons, and offline cache.
Demo actions remain local to the browser. Buddy matching, community publishing, uploads and event interest are not connected to live LPU systems. Verify official procedures and emergency contacts before real-world use.
